# Verify real Univer export fixtures

Use `real-univer-workbook.json` in this directory. It is generated by the installed Univer 0.25.0 runtime, using facade workbook/range mutations and `book.save()`. The generator is `scripts/create-univer-fidelity.cjs`; `manifest.json` lists labeled cases and limitations. Styles supplied to `setValue(ICellData)` are real API inputs, not hand-authored snapshot output. Do not confuse successful serialization with visual proof.

## Procedure

1. Load the JSON into the application's Univer instance. Inspect every labeled sheet and capture source rendering at a recorded zoom. Use the installed renderer to establish expected line breaks, alignment, colors and dimensions. Headless generation does not calculate canvas auto heights, so the fixtures deliberately set explicit row heights.
2. Export each sheet through the active item/shared-sheet/custom-component PDF and Excel paths. Preserve styles and print settings. Use a fresh copy of each fixture so tests do not modify the source artifact.
3. Save PDF/SVG/XLSX artifacts before assertions. Compile Typst and reopen XLSX; compare values, types, number formats, styles, row/column geometry, hidden dimensions and merges.
4. Compare rendered exports with the same Univer source, including rotated text, clip/overflow, number display text, fonts, rich-text Unicode offsets and border geometry. SVG selectable text rectangles are not exact glyph ink. Exclude glyph definitions when identifying table strokes and compose all element/ancestor transforms.
5. Classify each case as verified, approximate or unsupported. Add meaningful regression tests for mismatches and fix one feature group at a time. Keep the existing Check 1 B1 regression and numeric alignment tests passing.
6. Run `powershell -ExecutionPolicy Bypass -File scripts/verify-exports.ps1` and its `-SelfTest`; report actual exit codes and artifact paths.

## Logic

Resolve effective styles property by property using installed Univer precedence. Resolve geometry and displayed text using the installed runtime, not character-count heuristics or guessed defaults. Share the normalization model between writers where semantics match. PDF consumes displayed text; Excel preserves original values, formulas, and number formats. Measure and render rotated text under consistent constraints; alignment must use full cell content dimensions.

## Coverage boundaries

This is a broad cell-format laboratory, not every Univer feature. Charts/images, theme resolution, conditional formatting rules, paragraph lists, live formula calculation and canvas-derived auto-height need additional runtime-generated fixtures. Derive additions through public APIs or verified installed command definitions and save through Univer. Do not claim complete fidelity from this workbook alone.
